Preguntas Frecuentes

Todo lo que necesitas saber antes de empezar.

¿De quién es el código y la base de datos?

El código fuente y la base de datos te pertenecen al 100%. Te transferimos el repositorio de GitHub y la propiedad del proyecto en Supabase.

¿Hay reuniones o llamadas de sincronización?

No. Operamos de manera 100% asíncrona para maximizar la velocidad y reducir costes. Defines los requisitos en el formulario tras el pago y resolvemos cualquier duda por email.

¿Qué pasa si necesito algún ajuste tras la entrega?

Todos los planes incluyen un periodo de revisión para verificar que todos los endpoints funcionan exactamente como especificaste en el briefing.
